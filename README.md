### ⭐ Featured: [LiveEdit](https://github.com/clencyc/LiveEdit)
 
[![Stars](https://img.shields.io/github/stars/clencyc/LiveEdit?style=flat-square&color=3DDC84&logo=github)](https://github.com/clencyc/LiveEdit/stargazers)
[![Forks](https://img.shields.io/github/forks/clencyc/LiveEdit?style=flat-square&logo=github)](https://github.com/clencyc/LiveEdit/forks)
[![Live demo](https://img.shields.io/badge/Live_demo-live--edit--eight.vercel.app-000000?style=flat-square&logo=vercel&logoColor=white)](https://live-edit-eight.vercel.app/)
 
A real-time AI video editor powered by the **Gemini API**. Upload a video, chat with the AI about it, and get back an analysis with a suggested edit plan (cuts, key events, summary). It can also generate video with AI, and has a live mode for real-time interaction.
 
**How it's built**
 
- **Frontend:** React 19, TypeScript and Vite, deployed on Vercel
- **Backend:** Flask API served with Gunicorn
- **Background jobs:** Celery workers consuming a Redis (Upstash) queue, so long-running video work doesn't block the API
- **Processing:** FFmpeg for video work, Google Gemini for analysis and generation
- **Data:** Neon PostgreSQL
